## 第二週完成項目

- FHD H.264 RTSP 串流，可使用 VLC 即時觀看。
- 網頁顯示最新 JPEG 畫面，避免舊畫面持續累積延遲。
- YOLOv4-tiny 辨識人物與書本。
- SCRFD 人臉五點特徵估算低頭／抬頭。
- 連續辨識、數值平滑與雙門檻切換，降低瞬間誤判。
- 番茄鐘時間設定、開始、暫停與重設。
- 專心、不專心、離席、姿態不明時間及分心事件統計。
- 低頭專心時 LED 亮起；抬頭、無人或姿態不明時熄滅。
- 辨識結果逾時清除與 Wi-Fi 背景重連。

## 系統流程

```text
攝影機影像
  → YOLO 人物／書本辨識 + SCRFD 人臉特徵
  → 頭部姿態與連續一致判斷
  → 網頁狀態、統計、VLC 畫面與 LED 輸出
```

## 硬體與環境

- 開發板：AMB82-MINI（AmebaPro2 / RTL8735B）
- 鏡頭：JXF37
- Ameba Arduino：4.0.9
- Serial Monitor：115200 baud
- 不需要 SD 卡或外部網頁伺服器

## 注意事項

目前是以臉部特徵推估頭部方向，不是眼球追蹤。光線、側臉、遮擋、鏡頭高度及個人坐姿仍可能影響結果，第三週將依測試資料持續校正。

Wi-Fi 設定請由 `wifi_secrets.example.h` 複製建立本機 `wifi_secrets.h`；真實 SSID 與密碼不會上傳至 GitHub。
