# 1～2 分鐘操作影片拍攝腳本

影片要連續展示一次完整的「辨識 → 判斷 → 反應」，建議總長約 1 分 30 秒。

1. 拍攝 AMB82-MINI、鏡頭、LED 與桌上的書，簡短介紹第二週原型。
2. 同時呈現 VLC 即時影像與網頁儀表板，證明兩者皆已連線。
3. 在網頁把姿態確認時間設為 2 秒，按下開始。
4. 低頭看書並維持約 3 秒，拍到網頁顯示低頭／專心、專心時間增加及 LED 亮起。
5. 快速抬頭不到 1 秒後立即低頭，拍到狀態與事件數沒有改變，展示防止瞬間誤觸。
6. 再持續抬頭約 3～4 秒，拍到網頁切換為抬頭／不專心、LED 熄滅且事件數增加 1。
7. 重新低頭約 3 秒，拍到狀態恢復為專心且 LED 再次亮起。
8. 暫時離開畫面，展示無人／離席及舊姿態逾時清除。
9. 結尾顯示開始、暫停或重設操作，並說明目前不是眼球追蹤，第三週會校正門檻及改善光線、側臉與書本漏判。

拍攝時可用電腦錄製網頁與 VLC，再用手機從側面拍人與 LED，最後把手機畫面放在右下角。核心的「持續抬頭 → 狀態改變 → LED 熄滅 → 事件加一」盡量保持連續、不跳剪。
