# 第二週測試計畫

下列為第三週預定量測的條件、操作方法與通過標準。第二週交付重點是完成可操作的端到端原型，並先建立一致的驗收方式。

| 測試項目 | 操作方法 | 通過標準 |
|---|---|---|
| 開機／網路 | 板子重開，電腦連同一熱點 | 60 秒內可開啟網頁與 RTSP |
| 人物辨識 | 進入與離開畫面各 10 次 | 至少 8 次正確顯示有人／無人 |
| 低頭辨識 | 距離 60～120 cm，低頭維持，做 10 次 | 至少 8 次切換為低頭／專心 |
| 抬頭辨識 | 由低頭改為抬頭並維持，做 10 次 | 至少 8 次切換為抬頭／不專心 |
| 防止瞬間誤觸 | 快速抬頭後立即低頭 | 未達確認秒數時不切換 |
| 事件計數 | 抬頭後再低頭，重複 3 次 | 每次進入不專心只加 1，共增加 3 次 |
| 書本辨識 | 書本放入／移出畫面各 10 次 | 清楚入鏡時至少 7 次正確更新 |
| LED 輸出 | 分別維持低頭、抬頭與離席 | 低頭專心亮，其餘狀態熄滅 |
| 番茄鐘 | 以短時間測試開始、暫停、重設及切換 | 倒數、按鈕及階段狀態正確 |
| 影像延遲 | 揮手並連續觀看網頁 3 分鐘 | 延遲不持續累積，畫面不凍結 |
| 中斷重連 | 關閉熱點後重新開啟 | 免重新燒錄，恢復後可再次連線 |
| 無人逾時清除 | 人物離開畫面 | 約 3 秒內清除舊姿態並顯示無人 |

測試時應記錄光線、距離、角度、網路訊號與成功次數，第三週再依結果調整姿態門檻及確認秒數。
