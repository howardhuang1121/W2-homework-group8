# VLC、網頁與辨識流程測試

## 連線成功條件

1. Arduino Serial Monitor（115200 baud）顯示 `Wi-Fi connected.`。
2. 序列監控顯示 `Dashboard`、`Browser snapshot` 與 `VLC URL`。
3. 瀏覽器可開啟儀表板，狀態 API 顯示相機與 AI 已就緒。
4. VLC 貼入 RTSP 網址後可持續播放，且畫面上能看到辨識框與姿態文字。

目前 iPhone 熱點測試網址：

- 儀表板：`http://172.20.10.4/`
- 最新畫面：`http://172.20.10.4:81/snapshot`
- VLC：`rtsp://172.20.10.4:554`

## VLC 操作

1. 開啟 VLC。
2. 選擇「媒體 → 開啟網路串流」。
3. 貼上序列監控顯示的完整 RTSP 網址。
4. 按下播放。
5. 若延遲明顯，可在「顯示更多選項」降低網路快取。快取越低，延遲通常越小，但 Wi-Fi 不穩時可能更容易卡頓。

## 完整功能檢查

1. 在網頁設定姿態確認秒數並啟動番茄鐘。
2. 低頭維持超過設定秒數，確認顯示 `HEAD_DOWN`、專心時間增加且 LED 亮起。
3. 抬頭維持超過設定秒數，確認顯示 `HEAD_UP`、不專心時間及事件數增加且 LED 熄滅。
4. 快速抬頭後立即低頭，確認未達設定秒數時不會切換狀態。
5. 離開鏡頭，確認舊姿態會逾時清除並顯示無人／離席。

## 常見問題

- `sensor ID error` 或 `VOE not init`：Camera Options 應選 `JXF37`。
- 一直連不上 Wi-Fi：確認 SSID、密碼、2.4 GHz／相容模式，以及電腦和板子在同一網路。
- 更換網路後無法使用：本版固定為 iPhone 熱點位址 `172.20.10.4`，需修改程式內四個網路參數。
- VLC 無法開啟：先確認瀏覽器可開啟板子 IP，再核對 RTSP 連接埠為 `554`。
- 串流卡頓：把手機靠近板子、保持熱點頁面開啟，並適度調低 VLC 網路快取。
- 網頁畫面更新較慢：網頁採最新 JPEG 快照，優先避免舊畫面持續累積；高畫質即時觀看請使用 VLC。
- 看不到序列埠：使用板子的程式燒錄 Micro USB/UART 連接埠；`USB UVC CLASS` 不是燒錄用 COM 埠。
- 姿態誤判：調整攝影機高度、正面光源與座位距離，再依第三週測試結果校正門檻。
